## Main Demonstration Flow

1. Login as Sripad PK.
2. Create a document.
3. Edit and format the document.
4. Save the document.
5. Return to the dashboard.
6. Reopen the document and verify persistence.
7. Import a `.txt` or `.md` file.
8. Share a document with alex@example.com.
9. Switch to Alex Johnson.
10. Open "Shared with Me".
11. Open the shared document.
